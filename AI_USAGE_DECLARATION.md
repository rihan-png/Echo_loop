## How AI Was Used

AI assistance was used during the development of Echo Loop in the following ways:

### ✅ AI Assisted With:
- Generating boilerplate C# Unity scripts (PlayerController, LoopManager, etc.)
- Writing Unity Editor automation scripts for scene setup
- Identifying and fixing compiler errors and Unity API deprecations
- Suggesting project folder structure and code architecture
- Generating procedural audio tones without external audio files

### ✅ Developer Did (Human Contribution):
- **Game concept and design** — The Echo Loop mechanic (time loop + ghost clones) was conceived by the developer
- **Puzzle design** — Deciding where to place pressure plates, doors, and win zones
- **Playtesting** — All gameplay testing, feedback, and iteration
- **Decision making** — All architectural and design decisions were approved by the developer
- **Integration** — Running setup scripts, fixing scene wiring, and validating all functionality in Unity Editor
- **Debugging gameplay** — Identifying issues like wall sticking, ghost spawning, and UI failures through hands-on play
